# Design: Full Favicon Set and Web App Manifest

**Date:** 2026-10-30
**Status:** Validated 2026-10-30: option A icon (the gomddoc "g" in white on `#2563eb`), the full set from the
`favicons` skill, a manifest generated per site, a doctor warning for a partial override. Decision D53.

## Problem

The default theme shipped one `favicon.ico` and linked `/favicon.ico`. Serve answers that path through the static
fallback, but build writes static files only under `_assets/`, so built sites had no favicon. The seven
gomddoc-themes themes have no `static/` and no icon link. Nothing produced apple-touch, Android or maskable icons or a
manifest.

## Design

- **Files.** `cmd/gomddoc/assets/shared/static/`: `favicon.ico` (16/32/48), `favicon.svg`, `apple-touch-icon.png`
  (180, opaque, 20 px padding), `android-chrome-{192,512}.png`, `maskable-icon-{192,512}.png` (full-bleed, artwork in
  the central 80%). Every theme serves the shared layer.
- **Head.** `head-icons` in `head-shared.html.tmpl`, called from `head-meta`: the ICO with `sizes="48x48"`, the SVG
  with `sizes="any"`, the apple-touch icon, all through `assetURL`, and `/site.webmanifest` with
  `crossorigin="use-credentials"`. Each theme's `head` adds the two `theme-color` metas from its backgrounds,
  `theme.vars` `bg`/`dark-bg` first.
- **Manifest.** `server.GenerateWebManifest(meta)`: `name`/`short_name` from `meta.title`, `description` from
  `meta.description`, the four Android icons under `/_assets/`, `theme_color` `#2563eb`, `background_color`
  `theme.vars` `bg` or `#ffffff`, `standalone`, `start_url: /`.
  Serve answers `GET /site.webmanifest` behind auth; build writes `site.webmanifest`.
- **Partial override.** `assets.IconFindings`: icons found under `.gomddoc/` in any static layer of the active theme,
  mixed with built-in ones, give one `theme.icons-mixed` warning naming both lists. Added to the pipeline's findings.

## Testing

Go: manifest content and revalidation, the route behind auth, the icon finding table, the head links and
`theme-color` (defaults and `theme.vars`), the shared files embedded, the build output. The `favicons` skill's
`favicon-check.go` against a served site. gomddoc-themes: its gate renders every theme.
