# Design: Math Delimiters Without Single-Dollar Math

**Date:** 2026-10-30
**Status:** Validated 2026-10-30: no opt-in for single dollars, client-side change now, no backward compatibility.
Decision D52.

## Problem

The `katex` feature ran KaTeX's auto-render over the whole page with `$…$` as an inline delimiter. Any paragraph
holding two dollar amounts ("between $1,200 and $3,400") rendered the text between them as math. The workaround,
writing `USD` instead of `$`, put the burden on content authors.

## Design

- **Syntax.** Two delimiters only, the GitHub/GitLab conventions:
  - inline: `` $`…`$ ``, a code span with a `$` directly on each side; `` \$`code`$ `` keeps a literal sign and code;
  - display: a block opened by a line starting with `$$` and closed by a line ending with `$$`, on one line or
    several; it can interrupt a paragraph, like a code fence. A `$$` mid-paragraph is text.
  - Single `$` is never a delimiter. No opt-in, site-wide or per page.
- **Server side.** `MathExtension` in `internal/renderer/ext_math.go`: a block parser for `$$` (a raw block, so `_`,
  `*` and `\\` stay TeX) and an AST transformer on code spans. Both render `<gmd-math>` / `<gmd-math display>` with
  the HTML-escaped TeX. Gated by the `katex` feature, site-wide and per page; off, the syntax is plain Markdown.
- **Client side.** `gmd-math.mjs` defines `<gmd-math>` (light DOM, so the KaTeX stylesheet applies): it imports KaTeX
  from jsDelivr when the first element connects (no fetch on pages without math) and typesets its text once,
  `throwOnError: false`. `scripts-shared` inlines it in place of auto-render; `head-katex` keeps the stylesheet and
  adds `gmd-math[display]{display:block}`. Annotations skip `gmd-math`, so their text model is the same before and
  after KaTeX loads.
- **Compatibility.** None: `$x$` content must be rewritten. The release notes say so.

## Testing

- Go table tests (`internal/renderer/math_test.go`): prices, single-dollar pairs, inline math, escaping, adjacent
  spans, display blocks (multi-line, one line, content on marker lines, interrupting a paragraph, in a blockquote),
  fenced code, and the feature toggles (site off, page off, page on over site off).
- Vitest (`web/unit/math.test.mjs`) with KaTeX aliased to a stub: inline and display options, TeX read from the
  element, a single typeset when the element moves.
- Manual: `make run`, kitchen-sink page.
