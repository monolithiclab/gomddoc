# Design: Markdown at `.md` URLs, `llms.txt` and the MCP Registry

**Date:** 2026-10-30
**Status:** Validated 2026-10-30. Part of the lab's marketing plan
(`company/docs/plans/20261030.marketing.md`, Tasks 1–3). Decisions D54 and D55.

## Problem

An agent reads a gomddoc site best as Markdown, but finding it is hard:

- **Only one way in:** Markdown is reachable with `Accept: text/markdown` and nothing else. A pasted URL, a browser,
  a crawler or a static host has no way to ask for it.
- **The `.md` URL is taken:** `/guide.md`, the URL people guess, answers 301 to `/guide` (`ExtensionRedirect`, spec
  20260404.url-extension-stripping).
- **No index for agents:** there is no `llms.txt` to say which pages exist.
- **Not listed:** the built-in MCP server isn't in the MCP Registry, where agent users look for servers.

## Design

### Enriched Markdown at `.md` URLs (D54)

- **A `.md` or `.markdown` URL that resolves to a page** returns 200 with:
  - `Content-Type: text/markdown; charset=utf-8`;
  - the same body as the clean URL with `Accept: text/markdown`: `MarkdownPassthroughRenderer`'s output, frontmatter
    merged with related docs and prev/next;
  - `Link: <{canonical clean URL}>; rel="canonical"`, absolute with a domain, root-relative without one.
- **The extension wins over `Accept`.** `/guide.md` with `Accept: text/html` still gets Markdown.
- **The clean URL is unchanged:** canonical, HTML by default, Markdown by negotiation, `Vary: Accept`.
- **Every HTML page** links its Markdown with `<link rel="alternate" type="text/markdown" href="{page}.md">`, with the
  language prefix when there is one.
- **The redirect stays for other extensions.** Anything else in `strip_extensions` (`.html`, say) still answers 301.
- **One render path.** The `.md` request goes through the handler's passthrough path, the same one negotiated
  Markdown uses.
- **Special pages:** `/dir/index.md` and `/dir/README.md` serve the directory page. `/fr-FR/guide.md` serves the
  French page. A `.md` URL for a missing page is 404, not a redirect. `redirect_from` targets stay clean URLs.
- **`gomddoc build`** writes `{page}.md` next to `{page}/index.html` with the same body, so static hosts serve the
  same URLs. It stops writing any `.md` redirect stub.
- **No config key and no compatibility switch** (pre-1.0). The release notes and the `strip_extensions` doc tag say
  that `.md` no longer redirects.

### `llms.txt` (D55)

- **Where:** `GET /llms.txt`, `text/plain; charset=utf-8`, from serve, and `llms.txt` at the output root from build,
  with the same content. Each language also gets `/{lang}/llms.txt`, listing its own pages.
- **Format,** per llmstxt.org:
  - `# {site title}`;
  - `> {site description}`;
  - one `## {section}` per top-level navigation section;
  - under each, `- [{title}]({page URL}.md): {description}`;
  - a final line naming the MCP endpoint when `/_mcp/` is enabled.
- **What it lists:** the sitemap's page walk and URL rules, with the same domain handling (relative URLs without a
  domain). Pages with `robots: noindex` and `redirect_from` sources are left out.
- **Generated, not configured.** No config key, unless the sitemap has one to mirror.

### MCP Registry publication

- **`server.json` at the repo root:**
  - name `io.github.monolithiclab/gomddoc`;
  - one `oci` package `ghcr.io/monolithiclab/gomddoc:{version}`, stdio transport running `gomddoc mcp`;
  - a `remotes` entry only if a public `/_mcp/` endpoint is confirmed live.
- **Image label:** every image GoReleaser builds carries
  `io.modelcontextprotocol.server.name=io.github.monolithiclab/gomddoc`.
- **Release workflow:** after the image push, it sets the version from the tag and runs
  `mcp-publisher login github-oidc` then `mcp-publisher publish`. The job gets `id-token: write` only, and the
  binary is pinned by version and checksum. The tool is recorded in `docs/decisions.md`.
- **Lint guard:** `make lint` checks that `server.json` parses and that its name matches every image label.

### README and licence at install

- **Status:** the README Status and ROADMAP give the latest tag and its date.
- **Install section:** one sentence names who may use gomddoc for free and that any for-profit use, internal docs
  included, needs a commercial licence. It matches `LICENSE-COMMERCIAL.md`.
- **Free-licence form:** an issue form, "Free licence request", labelled `licence`.

## Testing

- **Server tests (`.md` URLs):**
  - the `.md` body equals the negotiated body;
  - `Accept: text/html` is ignored;
  - canonical `Link` with and without a domain;
  - the language prefix;
  - `index.md` and `README.md`;
  - a missing page is 404;
  - `.markdown`;
  - another stripped extension still redirects;
  - the HTML alternate link.

  Existing tests that assert the `.md` 301 are updated in the same commit.
- **Build test:** `{page}.md` beside the HTML, equal to the served body.
- **`llms.txt` tests:**
  - served, with its content type;
  - every navigation page once, and every `.md` link answers 200 from the same server;
  - `noindex` pages and redirect sources absent;
  - per-language files;
  - the MCP line only when MCP is on;
  - build output equal to serve;
  - relative URLs without a domain.
- **Registry lint:** fails on a name mismatch, proven once by breaking it. `goreleaser check` stays green.
