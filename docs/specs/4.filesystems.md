# Git Filesystem Provider Specification

> **Status: Completed and hardened.** The Git provider is implemented and has undergone security review. Key
> post-implementation changes: SSH TOFU fallback removed (fail closed via known_hosts), clone timeout enforced
> via `git.CloneContext()`, race condition between `ensureCloned()`/`Close()` fixed with `closed` flag, and
> `ErrNoRenderer` mapped to HTTP 415. See [architecture.md](../architecture.md) for current state.

## Overview

This document specifies the Git filesystem provider for gomddoc, enabling content serving directly from remote Git
repositories. The provider implements the existing `Provider` interface, allowing gomddoc to serve documentation from
GitHub, GitLab, Bitbucket, or any Git server without requiring manual cloning.

**Key Design Decisions:**

- **Library**: go-git (pure Go) - No CGO dependencies, embedded-friendly
- **Storage**: In-memory clone - No persistent disk cache, cleared on restart
- **Authentication**: Explicit SSH key file with known_hosts verification (no TOFU, no agent)
- **Branch Support**: Full branch/tag/commit reference support via URL fragment
- **Performance**: Shallow clone (depth=1) with lazy initialization and enforced timeout

## Motivation

Documentation often lives in Git repositories. Currently, gomddoc requires a local filesystem path, forcing users to:

1. Clone repositories manually
2. Set up CI/CD to sync content
3. Maintain multiple local copies for different branches

The Git provider eliminates this friction by cloning directly into memory, enabling:

- Serve documentation from any Git repository
- Switch branches via URL
- Support private repositories through SSH
- Minimal memory footprint with shallow clones
- Simple deployment (restart to update content)

## URL Scheme

### Syntax

```
git://[user@]host[:port]/path/to/repo[.git][#ref[:subdir]]
git+ssh://[user@]host[:port]/path/to/repo[.git][#ref[:subdir]]
git+https://host[:port]/path/to/repo[.git][#ref[:subdir]]
```

### Components

| Component | Required | Description            | Default         |
| --------- | -------- | ---------------------- | --------------- |
| Scheme    | Yes      | Protocol identifier    | -               |
| User      | No       | SSH username           | `git` (for SSH) |
| Host      | Yes      | Git server hostname    | -               |
| Port      | No       | Non-standard port      | 22/443/9418     |
| Path      | Yes      | Repository path        | -               |
| Ref       | No       | Branch, tag, or commit | `HEAD`          |
| Subdir    | No       | Subdirectory to serve  | `/` (root)      |

### Examples

```bash
# GitHub public repository (HTTPS, anonymous)
gomddoc -d "git+https://github.com/user/docs.git"

# GitHub with specific branch
gomddoc -d "git+https://github.com/user/docs#develop"

# GitHub private repository (SSH with agent)
gomddoc -d "git+ssh://git@github.com/org/private-docs#main"

# Serve only /docs subdirectory from monorepo
gomddoc -d "git+https://github.com/user/monorepo#main:docs"

# GitLab with tag reference
gomddoc -d "git://gitlab.com/group/project.git#v2.0.0"

# Self-hosted with non-standard SSH port
gomddoc -d "git+ssh://git@git.company.com:2222/team/docs"

# Commit hash reference (minimum 7 characters)
gomddoc -d "git+https://github.com/user/docs#a1b2c3d"
```

### Scheme Semantics

| Scheme         | Transport    | Authentication          | Use Case                     |
| -------------- | ------------ | ----------------------- | ---------------------------- |
| `git://`       | Git protocol | None (read-only)        | Public repositories, fastest |
| `git+ssh://`   | SSH          | SSH agent keys          | Private repositories         |
| `git+https://` | HTTPS        | Anonymous (public only) | Firewalled environments      |

**Note:** `git+https://` with authentication tokens is deferred to a future version.

## Architecture

### Why Clone is Required

**The Git protocol does not support fetching individual files.** Unlike HTTP file servers, Git transfers
objects in packfiles during clone/fetch operations. There is no "get blob X" command in the wire protocol.

This is a fundamental constraint of Git, not a library limitation. See:
- [Git Transfer Protocols](https://git-scm.com/book/en/v2/Git-Internals-Transfer-Protocols)
- [go-git Issue #713](https://github.com/go-git/go-git/issues/713) - Partial clone tracking

**Future improvement:** When go-git implements `--filter=blob:none` support ([PR #1000](https://github.com/go-git/go-git/pull/1000)
merged protocol-level support), we could fetch trees only and load blobs on-demand.

### Architecture

```
┌──────────────────────────────────────────────────────────────────┐
│                         Git Provider                             │
├──────────────────────────────────────────────────────────────────┤
│                                                                  │
│  ┌─────────────┐    ┌─────────────────┐    ┌─────────────────┐   │
│  │   Remote    │───▶│  memory.Storage │───▶│  *object.Tree   │   │
│  │  git clone  │    │  (object DB)    │    │  (file access)  │   │
│  └─────────────┘    └─────────────────┘    └─────────────────┘   │
│                                                    │             │
│  One-time on first request                         ▼             │
│  (lazy initialization)                    ┌─────────────────┐    │
│                                           │   ReadFile()    │    │
│                                           │   Stat()        │    │
│                                           └─────────────────┘    │
│                                                                  │
└──────────────────────────────────────────────────────────────────┘
```

**Flow:**

1. First `ReadFile()` triggers lazy clone into `memory.Storage`
2. Subsequent reads access cached `*object.Tree` (sub-millisecond)
3. Memory cleared on process restart (restart to pick up new content)

**To update content:** Restart the server. A future caching layer on top of `Provider` could handle
cache invalidation separately.

```go
// StorageFactory creates storage backends for Git repositories.
// This abstraction enables switching between memory and disk-based storage.
type StorageFactory func() (storage.Storer, error)

// MemoryStorageFactory returns a factory that creates in-memory storage.
// This is the default for ephemeral, fast-startup deployments.
func MemoryStorageFactory() StorageFactory {
    return func() (storage.Storer, error) {
        return memory.NewStorage(), nil
    }
}

// GitProvider implements Provider for remote Git repositories.
// It clones the repository into storage on first access and serves
// files from the object database.
//
// Storage Strategy:
// The provider uses storage.Storer interface, allowing both memory and
// disk-based backends. Memory storage (default) provides:
//   - Fast startup (no disk I/O)
//   - Ephemeral data (cleared on restart)
//   - Suitable for small-to-medium repositories
//
// Future disk-based storage will enable:
//   - Persistent cache across restarts
//   - Handling large repositories that exceed memory
//   - Faster restarts (incremental fetch vs full clone)
type GitProvider struct {
    // Configuration (immutable after construction)
    endpoint       *transport.Endpoint
    ref            string         // Branch, tag, or commit hash
    subdir         string         // Optional subdirectory to serve
    defaultIndex   string         // Default index file (e.g., "README.md")
    dirIndex       bool           // Enable directory listing
    cloneTimeout   time.Duration  // Timeout for clone/fetch operations
    maxFileSize    int64          // Maximum file size to serve
    storageFactory StorageFactory // Creates storage backend (default: memory)

    // Authentication (nil for anonymous)
    auth transport.AuthMethod

    // Lazily initialized state (protected by mu)
    mu         sync.RWMutex
    storage    storage.Storer    // Interface: memory.Storage or filesystem.Storage
    repo       *git.Repository
    tree       *object.Tree      // Cached root tree (or subdir tree)
    commitTime time.Time         // Commit timestamp for ModTime
    commitHash plumbing.Hash     // Resolved commit hash
}

const (
    defaultCloneTimeout = 60 * time.Second
    defaultMaxFileSize  = 50 * 1024 * 1024 // 50 MB
    minHashPrefixLen    = 7                // Minimum chars for commit hash matching
)
```

```go
// NewGitProvider creates a Git provider from a git:// URL.
//
// The provider clones lazily on first ReadFile/Stat call, not at construction.
// This allows fast startup and proper error reporting with HTTP context.
//
// Options:
//   - WithStorageFactory: Custom storage backend (default: memory)
//   - WithCloneTimeout: Clone operation timeout (default: 60s)
//   - WithMaxFileSize: Maximum file size to serve (default: 50MB)
//
// Errors:
//   - ErrInvalidGitURL: URL is malformed or uses unsupported scheme
//   - ErrGitAuthFailed: SSH agent unavailable or has no suitable keys
func NewGitProvider(gitURL, defaultIndex string, dirIndex bool, opts ...GitProviderOption) (*GitProvider, error) {
    endpoint, ref, subdir, err := parseGitURL(gitURL)
    if err != nil {
        return nil, &PathError{Op: "parse", Path: gitURL, Err: ErrInvalidGitURL}
    }

    auth, err := resolveAuth(endpoint)
    if err != nil {
        return nil, &PathError{Op: "auth", Path: gitURL, Err: err}
    }

    g := &GitProvider{
        endpoint:       endpoint,
        ref:            ref,
        subdir:         subdir,
        defaultIndex:   defaultIndex,
        dirIndex:       dirIndex,
        cloneTimeout:   defaultCloneTimeout,
        maxFileSize:    defaultMaxFileSize,
        storageFactory: MemoryStorageFactory(), // Default: in-memory
        auth:           auth,
    }

    for _, opt := range opts {
        opt(g)
    }

    return g, nil
}
```

## URL Parsing

Use standard library `net/url` combined with go-git's transport endpoint:

```go
// internal/provider/giturl.go

// parseGitURL parses a git URL into transport endpoint, ref, and subdir.
//
// Supported formats:
//   - git://host/path#ref
//   - git+ssh://[user@]host/path#ref
//   - git+https://host/path#ref:subdir
//
// The fragment (after #) contains: ref[:subdir]
// If ref is omitted, defaults to "HEAD".
// If subdir is omitted, serves from repository root.
func parseGitURL(rawURL string) (*transport.Endpoint, string, string, error) {
    // Normalize scheme for net/url parsing
    normalized := rawURL
    if strings.HasPrefix(rawURL, "git+ssh://") {
        normalized = "ssh://" + strings.TrimPrefix(rawURL, "git+ssh://")
    } else if strings.HasPrefix(rawURL, "git+https://") {
        normalized = "https://" + strings.TrimPrefix(rawURL, "git+https://")
    } else if strings.HasPrefix(rawURL, "git://") {
        normalized = "git://" + strings.TrimPrefix(rawURL, "git://")
    } else {
        return nil, "", "", fmt.Errorf("unsupported scheme: %s", rawURL)
    }

    u, err := url.Parse(normalized)
    if err != nil {
        return nil, "", "", fmt.Errorf("parse URL: %w", err)
    }

    if u.Host == "" {
        return nil, "", "", errors.New("missing host")
    }

    // Extract ref and subdir from fragment: "main:docs/api"
    ref := "HEAD"
    subdir := ""
    if u.Fragment != "" {
        parts := strings.SplitN(u.Fragment, ":", 2)
        ref = parts[0]
        if ref == "" {
            ref = "HEAD"
        }
        if len(parts) == 2 {
            subdir = strings.Trim(parts[1], "/")
        }
    }

    // Clear fragment before creating endpoint
    u.Fragment = ""

    // Use go-git's endpoint parsing for protocol-specific handling
    endpoint, err := transport.NewEndpoint(u.String())
    if err != nil {
        return nil, "", "", fmt.Errorf("invalid endpoint: %w", err)
    }

    return endpoint, ref, subdir, nil
}

// isGitURL checks if a string is a Git URL.
// Used by config validation to skip filesystem checks for Git URLs.
func isGitURL(s string) bool {
    return strings.HasPrefix(s, "git://") ||
           strings.HasPrefix(s, "git+ssh://") ||
           strings.HasPrefix(s, "git+https://")
}
```

## Core Operations

### Lazy Initialization

Clone happens on first access, not at construction:

```go
// ensureCloned performs lazy initialization of the repository.
// Safe for concurrent calls - only the first caller clones.
func (g *GitProvider) ensureCloned() error {
    // Fast path: already cloned
    g.mu.RLock()
    if g.repo != nil {
        g.mu.RUnlock()
        return nil
    }
    g.mu.RUnlock()

    // Slow path: need to clone
    g.mu.Lock()
    defer g.mu.Unlock()

    // Double-check after acquiring write lock
    if g.repo != nil {
        return nil
    }

    return g.cloneLocked()
}

func (g *GitProvider) cloneLocked() error {
    stor, err := g.storageFactory()
    if err != nil {
        return &PathError{Op: "storage", Path: g.endpoint.String(), Err: err}
    }
    g.storage = stor

    cloneOpts := &git.CloneOptions{
        URL:           g.endpoint.String(),
        Auth:          g.auth,
        Depth:         1,              // Shallow clone
        SingleBranch:  true,           // Only fetch requested ref
        Tags:          git.NoTags,     // Skip tags for speed
        ReferenceName: g.refToPlumbing(),
    }

    repo, err := git.Clone(g.storage, nil, cloneOpts)
    if err != nil {
        return g.classifyCloneError(err)
    }
    g.repo = repo

    // Resolve the reference to a commit
    if err := g.resolveCommitLocked(); err != nil {
        return err
    }

    // Cache the tree for fast file access
    return g.cacheTreeLocked()
}

func (g *GitProvider) refToPlumbing() plumbing.ReferenceName {
    // Check if ref looks like a branch name
    if !strings.ContainsAny(g.ref, "^~:") && len(g.ref) < 40 {
        return plumbing.NewBranchReferenceName(g.ref)
    }
    return plumbing.HEAD
}

func (g *GitProvider) resolveCommitLocked() error {
    // Try to resolve as revision (branch, tag, or commit hash)
    hash, err := g.repo.ResolveRevision(plumbing.Revision(g.ref))
    if err != nil {
        // Fallback: try HEAD if ref resolution fails
        if g.ref == "HEAD" {
            head, err := g.repo.Head()
            if err != nil {
                return fmt.Errorf("resolve HEAD: %w", err)
            }
            g.commitHash = head.Hash()
        } else {
            return &PathError{Op: "resolve", Path: g.ref, Err: ErrGitRefNotFound}
        }
    } else {
        g.commitHash = *hash
    }

    // Get commit for timestamp
    commit, err := g.repo.CommitObject(g.commitHash)
    if err != nil {
        return fmt.Errorf("get commit: %w", err)
    }
    g.commitTime = commit.Author.When

    return nil
}

func (g *GitProvider) cacheTreeLocked() error {
    commit, err := g.repo.CommitObject(g.commitHash)
    if err != nil {
        return fmt.Errorf("get commit: %w", err)
    }

    tree, err := commit.Tree()
    if err != nil {
        return fmt.Errorf("get tree: %w", err)
    }

    // If subdir specified, navigate to it
    if g.subdir != "" {
        subtree, err := tree.Tree(g.subdir)
        if err != nil {
            return &PathError{Op: "subdir", Path: g.subdir, Err: ErrNotFound}
        }
        tree = subtree
    }

    g.tree = tree
    return nil
}

func (g *GitProvider) classifyCloneError(err error) error {
    errStr := err.Error()
    switch {
    case strings.Contains(errStr, "authentication"):
        return &PathError{Op: "clone", Path: g.endpoint.String(), Err: ErrGitAuthFailed}
    case strings.Contains(errStr, "could not read Username"):
        return &PathError{Op: "clone", Path: g.endpoint.String(), Err: ErrGitAuthFailed}
    case strings.Contains(errStr, "connection refused"):
        return &PathError{Op: "clone", Path: g.endpoint.String(), Err: ErrGitConnectFailed}
    case strings.Contains(errStr, "repository not found"):
        return &PathError{Op: "clone", Path: g.endpoint.String(), Err: ErrNotFound}
    default:
        return &PathError{Op: "clone", Path: g.endpoint.String(), Err: err}
    }
}
```

### ReadFile

```go
func (g *GitProvider) ReadFile(requestPath string) ([]byte, string, error) {
    if err := g.ensureCloned(); err != nil {
        return nil, "", err
    }

    g.mu.RLock()
    defer g.mu.RUnlock()

    cleanPath := normalizePath(requestPath)

    // Handle root directory
    if cleanPath == "." {
        return g.handleDirectoryLocked(".", requestPath)
    }

    // Try to get as file first
    file, err := g.tree.File(cleanPath)
    if err == nil {
        return g.readFileLocked(file, requestPath)
    }

    // Try as directory
    if err == object.ErrFileNotFound {
        _, treeErr := g.tree.Tree(cleanPath)
        if treeErr == nil {
            return g.handleDirectoryLocked(cleanPath, requestPath)
        }
    }

    return nil, "", &PathError{Op: "read", Path: requestPath, Err: ErrNotFound}
}

func (g *GitProvider) readFileLocked(file *object.File, requestPath string) ([]byte, string, error) {
    // Check file size limit
    if file.Size > g.maxFileSize {
        return nil, "", &PathError{
            Op:   "read",
            Path: requestPath,
            Err:  fmt.Errorf("file too large: %d bytes (max %d)", file.Size, g.maxFileSize),
        }
    }

    // Check for Git LFS pointer
    if file.Size < 200 { // LFS pointers are small
        content, err := file.Contents()
        if err != nil {
            return nil, "", &PathError{Op: "read", Path: requestPath, Err: err}
        }
        if isLFSPointer(content) {
            return nil, "", &PathError{
                Op:   "read",
                Path: requestPath,
                Err:  errors.New("Git LFS files not supported; file is a pointer"),
            }
        }
        mimeType := detectMIME(requestPath)
        return []byte(content), mimeType, nil
    }

    content, err := file.Contents()
    if err != nil {
        return nil, "", &PathError{Op: "read", Path: requestPath, Err: err}
    }

    mimeType := detectMIME(requestPath)
    return []byte(content), mimeType, nil
}

func isLFSPointer(content string) bool {
    return strings.HasPrefix(content, "version https://git-lfs.github.com/")
}

func detectMIME(filePath string) string {
    mimeType := mime.TypeByExtension(path.Ext(filePath))
    if mimeType == "" {
        return "application/octet-stream"
    }
    return mimeType
}

func normalizePath(requestPath string) string {
    if requestPath == "/" || requestPath == "" {
        return "."
    }
    clean := path.Clean(requestPath)
    return strings.TrimPrefix(clean, "/")
}
```

### Stat

```go
func (g *GitProvider) Stat(requestPath string) (fs.FileInfo, error) {
    if err := g.ensureCloned(); err != nil {
        return nil, err
    }

    g.mu.RLock()
    defer g.mu.RUnlock()

    cleanPath := normalizePath(requestPath)

    // Root directory
    if cleanPath == "." {
        return &gitFileInfo{
            name:    "/",
            size:    0,
            mode:    fs.ModeDir | 0755,
            modTime: g.commitTime,
            isDir:   true,
        }, nil
    }

    // Try as file
    file, err := g.tree.File(cleanPath)
    if err == nil {
        return &gitFileInfo{
            name:    path.Base(cleanPath),
            size:    file.Size,
            mode:    file.Mode.ToOSFileMode(),
            modTime: g.commitTime,
            isDir:   false,
        }, nil
    }

    // Try as directory
    _, err = g.tree.Tree(cleanPath)
    if err == nil {
        return &gitFileInfo{
            name:    path.Base(cleanPath),
            size:    0,
            mode:    fs.ModeDir | 0755,
            modTime: g.commitTime,
            isDir:   true,
        }, nil
    }

    return nil, &PathError{Op: "stat", Path: requestPath, Err: ErrNotFound}
}

// gitFileInfo implements fs.FileInfo for Git objects
type gitFileInfo struct {
    name    string
    size    int64
    mode    fs.FileMode
    modTime time.Time
    isDir   bool
}

func (fi *gitFileInfo) Size() int64        { return fi.size }
func (fi *gitFileInfo) Mode() fs.FileMode  { return fi.mode }
func (fi *gitFileInfo) ModTime() time.Time { return fi.modTime }
func (fi *gitFileInfo) IsDir() bool        { return fi.isDir }
func (fi *gitFileInfo) Sys() any           { return nil }
```

### Directory Handling

```go
func (g *GitProvider) handleDirectoryLocked(cleanPath, requestPath string) ([]byte, string, error) {
    // Determine which tree to use
    var dirTree *object.Tree
    if cleanPath == "." {
        dirTree = g.tree
    } else {
        var err error
        dirTree, err = g.tree.Tree(cleanPath)
        if err != nil {
            return nil, "", &PathError{Op: "read", Path: requestPath, Err: ErrNotFound}
        }
    }

    // Try default index file
    indexPath := g.defaultIndex
    indexFile, err := dirTree.File(indexPath)
    if err == nil {
        content, err := indexFile.Contents()
        if err != nil {
            return nil, "", &PathError{Op: "read", Path: requestPath, Err: err}
        }
        mimeType := detectMIME(g.defaultIndex)
        return []byte(content), mimeType, nil
    }

    // Directory listing disabled
    if !g.dirIndex {
        return nil, "", &PathError{Op: "list", Path: requestPath, Err: ErrDirListingDisabled}
    }

    // Generate directory listing
    entries, err := g.listDirectoryLocked(dirTree)
    if err != nil {
        return nil, "", &PathError{Op: "list", Path: requestPath, Err: err}
    }

    content := GenerateMarkdownListing(requestPath, entries)
    return content, "text/markdown; charset=utf-8", nil
}

func (g *GitProvider) listDirectoryLocked(tree *object.Tree) ([]fs.DirEntry, error) {
    var entries []fs.DirEntry

    for _, entry := range tree.Entries {
        // Skip hidden files
        if strings.HasPrefix(entry.Name, ".") {
            continue
        }

        isDir := entry.Mode == filemode.Dir
        entries = append(entries, &gitDirEntry{
            name:     entry.Name,
            isDir:    isDir,
            fileMode: entry.Mode.ToOSFileMode(),
            size:     0, // Size requires loading blob, skip for listing
            modTime:  g.commitTime,
        })
    }

    // Sort: directories first, then alphabetically
    sort.Slice(entries, func(i, j int) bool {
        iDir := entries[i].IsDir()
        jDir := entries[j].IsDir()
        if iDir != jDir {
            return iDir
        }
        return entries[i].Name() < entries[j].Name()
    })

    return entries, nil
}

// gitDirEntry implements fs.DirEntry for Git tree entries
type gitDirEntry struct {
    name     string
    isDir    bool
    fileMode fs.FileMode
    size     int64
    modTime  time.Time
}

func (e *gitDirEntry) Name() string      { return e.name }
func (e *gitDirEntry) IsDir() bool       { return e.isDir }
func (e *gitDirEntry) Type() fs.FileMode { return e.fileMode.Type() }

func (e *gitDirEntry) Info() (fs.FileInfo, error) {
    return &gitFileInfo{
        name:    e.name,
        size:    e.size,
        mode:    e.fileMode,
        modTime: e.modTime,
        isDir:   e.isDir,
    }, nil
}
```

### DefaultIndex and Close

```go
func (g *GitProvider) DefaultIndex() string {
    return g.defaultIndex

func (g *GitProvider) Close() error {
    g.mu.Lock()
    defer g.mu.Unlock()

    // Clear cached state - allows GC to reclaim memory
    g.repo = nil
    g.tree = nil
    g.storage = nil

    return nil
}
```

**Note:** To refresh content, restart the server. This keeps the provider simple and stateless
from a cache-invalidation perspective. A `Refresh()` method may be added in a future version.

## SSH Authentication

```go
// internal/provider/git_auth.go

import (
    "log/slog"
    "os"

    "github.com/go-git/go-git/v5/plumbing/transport"
    "github.com/go-git/go-git/v5/plumbing/transport/ssh"
    gossh "golang.org/x/crypto/ssh"
)

// resolveAuth determines the authentication method for the endpoint.
func resolveAuth(endpoint *transport.Endpoint) (transport.AuthMethod, error) {
    switch endpoint.Protocol {
    case "ssh":
        return setupSSHAuth(endpoint.User)
    case "git":
        return nil, nil // Git protocol is anonymous
    case "https", "http":
        return nil, nil // Anonymous HTTPS (token auth deferred)
    default:
        return nil, nil
    }
}

func setupSSHAuth(user string) (transport.AuthMethod, error) {
    if user == "" {
        user = "git"
    }

    auth, err := ssh.NewSSHAgentAuth(user)
    if err != nil {
        return nil, fmt.Errorf("SSH agent: %w (is SSH_AUTH_SOCK set?)", err)
    }

    // Configure host key verification
    auth.HostKeyCallback = createHostKeyCallback()

    return auth, nil
}

func createHostKeyCallback() gossh.HostKeyCallback {
    // Try to use known_hosts file
    knownHostsPath := os.ExpandEnv("$HOME/.ssh/known_hosts")
    callback, err := ssh.NewKnownHostsCallback(knownHostsPath)
    if err == nil {
        return callback
    }

    // Fallback: log warning and accept (TOFU)
    slog.Warn("known_hosts not available, accepting all host keys (TOFU)",
        slog.String("path", knownHostsPath),
        slog.Any("error", err),
    )

    return func(hostname string, remote gossh.Addr, key gossh.PublicKey) error {
        slog.Debug("Accepting host key",
            slog.String("host", hostname),
            slog.String("key_type", key.Type()),
        )
        return nil
    }
}
```

## Performance Considerations

### Memory Optimization Strategies

The Git provider uses three strategies to minimize memory footprint:

| Strategy | Option | Effect |
|----------|--------|--------|
| **Shallow clone** | `Depth: 1` | Only fetch latest commit, no history |
| **Single branch** | `SingleBranch: true` | Skip other branches entirely |
| **No tags** | `Tags: git.NoTags` | Skip tag objects |

Combined, these reduce clone size by **10-100x** compared to a full clone.

### What Subdirectory Does (and Doesn't) Do

The subdirectory option (`#main:docs`) provides **logical filtering**, not fetch optimization:

```bash
gomddoc -d "git+https://github.com/user/monorepo#main:docs"
```

| Aspect | Behavior |
|--------|----------|
| **Access control** | Only `/docs` subtree is accessible via HTTP |
| **Path translation** | `/` maps to `/docs` in the repo |
| **Network transfer** | ⚠️ Still fetches entire repo (shallow) |
| **Memory usage** | ⚠️ Still stores all blobs in memory |

**Why?** The Git protocol transfers packfiles, not individual directories. Sparse checkout
(`SparseCheckoutDirectories` in go-git) only affects working directory, not object storage.

**Future improvement:** When go-git exposes `--filter=blob:none`, we could defer blob fetching
until accessed, making subdirectory filtering truly efficient.

### Network Operations

| Operation | When | Latency |
|-----------|------|---------|
| Clone | First `ReadFile` or `Stat` | 1-10s (depends on repo size) |
| ReadFile | After clone | <1ms (memory access) |
| Stat | After clone | <1ms (memory access) |
| Close | On shutdown | Immediate |

### Memory Footprint Examples

| Repository Type | Approximate Size | Memory Usage |
|-----------------|------------------|--------------|
| Small docs repo | 100 files, 1MB | ~2-3 MB |
| Medium docs repo | 500 files, 10MB | ~15-20 MB |
| Large monorepo (docs subdir) | 10,000 files total | ~50-100 MB* |

*Monorepos fetch all files even with subdirectory filter. For large monorepos,
prefer cloning to disk and using the filesystem provider.

### Recommendations

| Environment | Strategy |
|-------------|----------|
| Development | Use Git provider directly |
| Preview/Staging | Git provider + CDN cache |
| High-traffic Production | Clone to disk, use filesystem provider |
| Large monorepos | Clone to disk, use filesystem provider |

## Storage Strategy

### Interface-Based Design

The GitProvider uses go-git's `storage.Storer` interface rather than a concrete implementation.
This enables pluggable storage backends without changing the provider logic:

```go
// storage.Storer is go-git's unified storage interface
// Both memory.Storage and filesystem.Storage implement it
type Storer interface {
    storer.EncodedObjectStorer
    storer.ReferenceStorer
    storer.ShallowStorer
    storer.IndexStorer
    config.ConfigStorer
    ModuleStorer
}
```

### Storage Backends

| Backend | Implementation | Use Case | Lifecycle |
|---------|----------------|----------|-----------|
| **Memory** (default) | `memory.Storage` | Small-medium repos, ephemeral deployments | Cleared on restart |
| **Filesystem** (future) | `filesystem.Storage` | Large repos, persistent cache | Survives restarts |

### Current Implementation: Memory Storage

The default `MemoryStorageFactory()` provides:

- **Zero disk I/O**: All Git objects stored in RAM
- **Fast startup**: No cache validation needed
- **Simple cleanup**: Process exit reclaims all memory
- **Predictable behavior**: Restart = fresh clone

**Trade-offs:**

- Memory usage scales with repository size
- Full re-clone on every restart
- Not suitable for repositories > 100MB

### Future: Disk-Based Storage (Deferred)

A future `FilesystemStorageFactory` will enable persistent caching:

```go
// internal/provider/git_storage.go (future implementation)

import (
    "github.com/go-git/go-billy/v5/osfs"
    "github.com/go-git/go-git/v5/plumbing/cache"
    "github.com/go-git/go-git/v5/storage/filesystem"
)

// FilesystemStorageFactory returns a factory that creates disk-based storage.
// The cache directory persists across restarts for faster subsequent launches.
func FilesystemStorageFactory(cacheDir string) StorageFactory {
    return func() (storage.Storer, error) {
        fs := osfs.New(cacheDir)
        return filesystem.NewStorage(fs, cache.NewObjectLRUDefault()), nil
    }
}
```

**Benefits of disk storage:**

- **Incremental updates**: `git fetch` instead of full clone
- **Faster restarts**: Existing objects reused
- **Large repo support**: Not limited by available RAM
- **Cache sharing**: Multiple instances can share cache (with locking)

**Configuration (future):**

```bash
# Environment variable
GOMDDOC_GIT_CACHE=/var/cache/gomddoc/git

# Or CLI flag
gomddoc -d "git+https://..." --git-cache /var/cache/gomddoc/git
```

### Storage Selection Guidelines

| Scenario | Recommended Storage | Rationale |
|----------|---------------------|-----------|
| Ephemeral containers (K8s, Lambda) | Memory | No persistent disk, fast cold start |
| Small docs repos (<10MB) | Memory | Simple, no configuration |
| Medium repos (10-100MB) | Memory or Disk | Depends on restart frequency |
| Large repos (>100MB) | Disk | Avoid OOM, faster restarts |
| CI/CD preview deployments | Memory | Ephemeral by design |
| Production with CDN | Memory | CDN caches rendered content |
| Self-hosted long-running | Disk | Minimize clone frequency |

### Thread Safety Considerations

Both storage backends are thread-safe for concurrent reads after initialization.
The `GitProvider.mu` mutex protects:

1. **Lazy initialization**: Only one goroutine performs the clone
2. **Storage assignment**: The `storage` field write is protected
3. **Tree caching**: The cached `*object.Tree` reference

After initialization, concurrent `ReadFile` and `Stat` calls are safe because:
- `storage.Storer` implementations are read-safe after population
- `*object.Tree` traversal is read-only
- No mutations occur after `cloneLocked()` completes

## Security Considerations

### SSH Key Security

- Keys never leave SSH agent process
- Private key material not accessible to gomddoc
- Agent forwarding supported for CI/CD environments
- SSH_AUTH_SOCK is the only requirement

### Host Key Verification

**Default behavior:** Check `~/.ssh/known_hosts`

**Fallback:** If known_hosts unavailable, accept with warning (TOFU)

**Logging:** Unknown hosts logged at DEBUG level with key fingerprint

### Path Traversal Protection

- go-git's `tree.File()` and `tree.Tree()` reject `..` paths
- Subdirectory option restricts access to subtree
- Consistent with filesystem provider behavior

### Hidden Files

Same rules as filesystem provider:

- `.git/`, `.env`, etc. blocked at middleware level
- Hidden file filtering in directory listings
- `.well-known/` allowed per RFC 8615

### File Size Limits

- Default maximum: 50 MB per file
- Prevents memory exhaustion from large binaries
- Configurable via future options API

### Git LFS Detection

- LFS pointer files detected and rejected (501 Not Implemented)
- Prevents serving pointer content instead of actual files
- Clear error message guides user to solution
