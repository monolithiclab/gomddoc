# Content Rendering System Specification

## Overview

Gomddoc needs a unified, MIME-type based content rendering system. The design prioritizes simplicity:

- Provider detects MIME types using Go stdlib `mime` package with normalization
- Renderers self-declare supported MIME types (no hardcoded registry mappings)
- Only 2 renderers: **MarkdownRenderer** and **PassthroughRenderer** (using `*/*` wildcard)
- Handler wraps `text/html` output in templates, passes through everything else
- Directory listings handled by provider as markdown (when DirIndex enabled)
- HTTP-compliant Accept header negotiation with stable sort
- Production-ready error handling with sentinel errors and proper status codes

## Current State Analysis

### Existing Architecture

```
Request → Handler.ServeMarkdown → Provider.ReadFile → Processor.Process → TemplateRenderer.Render → HTTP Response
```

**Components:**

- `Processor`: Transforms markdown bytes → HTML bytes
- `TemplateRenderer`: Wraps HTML in templates (layout, breadcrumbs)
- `Handler`: Orchestrates the flow (only for markdown)

**Limitations:**

- Hardcoded to markdown only
- No support for images, CSS, JS, JSON, HTML, directories
- No MIME type detection or normalization
- No renderer registry
- Provider doesn't return MIME types
- No HTTP content negotiation

## Design Principles

1. **Simplicity**: Only 2 renderers for all content types
2. **Convention over Configuration**: MIME types as universal identifiers
3. **Self-Declaration**: Renderers expose supported MIME types
4. **Separation of Concerns**:
   - Provider: File I/O + MIME detection
   - Renderer: Content transformation
   - Handler: Template wrapping decision + HTTP response + content negotiation
5. **Go stdlib First**: Use `mime` package for type detection and normalization
6. **HTTP Compliance**: Accept header negotiation, proper status codes, Content-Length
7. **Production Ready**: Error wrapping, classification, structured logging
8. **stdlib Compatibility**: Provider works with `fs.FS` (no context parameter)

## Core Concepts

### MIME Type Normalization

**Problem:** `mime.TypeByExtension()` returns `"text/html; charset=utf-8"` but renderers register `"text/html"`.

**Solution:**

```go
// NormalizeMimeType strips parameters from MIME types
// Example: "text/html; charset=utf-8" → "text/html"
func NormalizeMimeType(mimeType string) string {
    mediaType, _, err := mime.ParseMediaType(mimeType)
    if err != nil {
        return mimeType // Malformed - return as-is
    }
    return mediaType
}
```

Used in:

- `Registry.Get()` - normalize before lookup
- `Handler.ServeContent()` - normalize before `text/html` comparison
- Always preserve full MIME type (with charset) for HTTP `Content-Type` header

### MIME Type Flow

```
1. Provider.ReadFile(path) → (content []byte, mimeType string, error)
                                         ↓
2. Handler parses Accept header, validates client accepts mimeType
                                         ↓
3. Registry.Get(NormalizeMimeType(mimeType)) → ContentRenderer
                                         ↓
4. Renderer.Render(ctx, content) → (output []byte, outputMimeType string, error)
                                         ↓
5. Handler Decision:
   if NormalizeMimeType(outputMimeType) == "text/html" → Wrap in layout.html.tmpl
   else → Write directly to HTTP response with full MIME type
```

### Registry Wildcard Matching

**Lookup Order:**

1. Exact match: `"text/markdown"`
2. Type wildcard: `"text/*"`
3. Catch-all: `"*/*"`

**Collision Handling:** Warn and override

```go
func (r *DefaultRegistry) Register(renderer ContentRenderer) {
    for _, mimeType := range renderer.SupportedMimeTypes() {

            slog.Warn("Overriding renderer for MIME type",
                slog.String("mime_type", mimeType),
                slog.String("old_renderer", fmt.Sprintf("%T", existing)),
                slog.String("new_renderer", fmt.Sprintf("%T", renderer)),
            )
        }
        r.renderers[mimeType] = renderer
    }
}
```

## Architecture Design

### Interface Definitions

```go
// ContentRenderer transforms content from input MIME type to output MIME type
type ContentRenderer interface {
    // SupportedMimeTypes returns MIME types this renderer can process
    // Use normalized MIME types (no charset parameters)
    SupportedMimeTypes() []string

    // Render processes content
    // Returns: (output content, output MIME type, error)
    // Empty output MIME type means "use input MIME type" (passthrough)
    Render(ctx context.Context, content []byte) ([]byte, string, error)
}

// RendererRegistry manages MIME type → renderer mappings
type RendererRegistry interface {
    // Register adds renderer and auto-maps all its supported MIME types
    // Logs warning on collision, then overrides
    Register(renderer ContentRenderer)

    // Get retrieves renderer for a MIME type
    // Supports wildcard matching: exact → type/* → */*
    // Returns error if no renderer found
    Get(mimeType string) (ContentRenderer, error)
}
```

### Provider Interface

```go
type Provider interface {
    // ReadFile reads file content and detects MIME type
    // Returns full MIME type with parameters (e.g., "text/html; charset=utf-8")
    // NO context parameter - maintains stdlib fs.FS compatibility
    ReadFile(path string) (content []byte, mimeType string, error)

    // Stat returns file info (used for directory detection)
    Stat(path string) (fs.FileInfo, error)

    DefaultIndex() string
    Close() error
}
```

### Accept Header Negotiation

```go
// internal/server/accept.go
package server

import (
    "mime"
    "sort"
    "strconv"
    "strings"
)

type MediaType struct {
    Type    string
    Subtype string
    Q       float64
    Full    string
}

func ParseAccept(acceptHeader string) []MediaType {
    if acceptHeader == "" {
        return []MediaType{{Type: "*", Subtype: "*", Q: 1.0, Full: "*/*"}}
    }

    var types []MediaType
    for _, part := range strings.Split(acceptHeader, ",") {
        mediaType, params, err := mime.ParseMediaType(strings.TrimSpace(part))
        if err != nil {
            continue
        }

        q := 1.0
        if qStr, ok := params["q"]; ok {
            if qVal, err := strconv.ParseFloat(qStr, 64); err == nil {
                q = qVal
            }
        }

        parts := strings.Split(mediaType, "/")
        if len(parts) == 2 {
            types = append(types, MediaType{
                Type:    parts[0],
                Subtype: parts[1],
                Q:       q,
                Full:    mediaType,
            })
        }
    }

    // Stable sort preserves client preference order for equal q-values
    sort.SliceStable(types, func(i, j int) bool {
        return types[i].Q > types[j].Q
    })

    return types
}

func (mt MediaType) Matches(mimeType string) bool {
    parts := strings.Split(mimeType, "/")
    if len(parts) != 2 {
        return false
    }

    if mt.Type == "*" {
        return true // */*
    }
    if mt.Type != parts[0] {
        return false
    }
    if mt.Subtype == "*" {
        return true // text/*
    }
    return mt.Subtype == parts[1]
}
```

### Built-in Renderers

#### 1. MarkdownRenderer

```go
// internal/renderer/markdown.go
package renderer

import (
    "context"
    "mime"

    "github.com/gomarkdown/markdown"
    "github.com/gomarkdown/markdown/html"
    "github.com/gomarkdown/markdown/parser"
)

func init() {
    // Register markdown MIME types
    // Co-located with renderer that owns this mapping
    mime.AddExtensionType(".md", "text/markdown")
    mime.AddExtensionType(".markdown", "text/markdown")
}

type MarkdownRenderer struct {
    extensions   parser.Extensions
    htmlRenderer *html.Renderer
}

func NewMarkdownRenderer() *MarkdownRenderer {
    extensions := parser.CommonExtensions | parser.AutoHeadingIDs | parser.NoEmptyLineBeforeBlock
    htmlFlags := html.CommonFlags
    opts := html.RendererOptions{Flags: htmlFlags}
    renderer := html.NewRenderer(opts)

    return &MarkdownRenderer{
        extensions:   extensions,
        htmlRenderer: renderer,
    }
}

func (m *MarkdownRenderer) SupportedMimeTypes() []string {
    return []string{"text/markdown"}
}

func (m *MarkdownRenderer) Render(ctx context.Context, content []byte) ([]byte, string, error) {
    // Check context before expensive operation
    if err := ctx.Err(); err != nil {
        return nil, "", err
    }

    // Create new parser for each render (library constraint - DO NOT pool)
    p := parser.NewWithExtensions(m.extensions)
    doc := p.Parse(content)

    // Check context after parsing, before rendering
    if err := ctx.Err(); err != nil {
        return nil, "", err
    }

    html := markdown.Render(doc, m.htmlRenderer)
    return html, "text/html; charset=utf-8", nil
}
```

**Input:** `text/markdown`
**Output:** `text/html; charset=utf-8`
**Template Wrapping:** YES (Handler detects normalized `text/html`)
**Context Checks:** Before and after parsing
**Parser Pooling:** ❌ DO NOT POOL (library constraint)

### Registry Implementation

```go
// internal/renderer/registry.go
package renderer

import (
    "fmt"
    "log/slog"
    "strings"
    "sync"
)

type DefaultRegistry struct {
    renderers map[string]ContentRenderer
    mu        sync.RWMutex
}

func NewDefaultRegistry() *DefaultRegistry {
    return &DefaultRegistry{
        renderers: make(map[string]ContentRenderer),
    }
}

func (r *DefaultRegistry) Register(renderer ContentRenderer) {
    r.mu.Lock()
    defer r.mu.Unlock()

    for _, mimeType := range renderer.SupportedMimeTypes() {
        if existing, ok := r.renderers[mimeType]; ok {
            slog.Warn("Overriding renderer for MIME type",
                slog.String("mime_type", mimeType),
                slog.String("old_renderer", fmt.Sprintf("%T", existing)),
                slog.String("new_renderer", fmt.Sprintf("%T", renderer)),
            )
        }
        r.renderers[mimeType] = renderer
    }
}

func (r *DefaultRegistry) Get(mimeType string) (ContentRenderer, error) {
    r.mu.RLock()
    defer r.mu.RUnlock()

    normalized := NormalizeMimeType(mimeType)

    // Try exact match first
    if renderer, ok := r.renderers[normalized]; ok {
        return renderer, nil
    }

    // Try type/* wildcard
    parts := strings.Split(normalized, "/")
    if len(parts) == 2 {
        typeWildcard := parts[0] + "/*"
        if renderer, ok := r.renderers[typeWildcard]; ok {
            return renderer, nil
        }
    }

    // Try */* wildcard (PassthroughRenderer)
    if renderer, ok := r.renderers["*/*"]; ok {
        return renderer, nil
    }

    return nil, fmt.Errorf("no renderer for MIME type: %s", normalized)
}
```

### Provider Implementation

```go
// internal/provider/filesystem.go
type FilesystemProvider struct {
    root         fs.StatFS  // ✅ Interface value, not pointer
    defaultIndex string
    dirIndex     bool
}

func NewFilesystemProvider(dir, defaultIndex string, dirIndex bool) (*FilesystemProvider, error) {
    fsys := os.DirFS(dir)

    // Type assertion to fs.StatFS (needed for Stat() method)
    statFS, ok := fsys.(fs.StatFS)
    if !ok {
        return nil, fmt.Errorf("filesystem does not support Stat: %s", dir)
    }

    return &FilesystemProvider{
        root:         statFS,
        defaultIndex: defaultIndex,
        dirIndex:     dirIndex,
    }, nil
}

func (f *FilesystemProvider) ReadFile(path string) ([]byte, string, error) {
    cleanPath := strings.TrimPrefix(path, "/")

    // Check if path is directory
    info, err := fs.Stat(f.root, cleanPath)
    if err != nil {
        return nil, "", fmt.Errorf("stat %s: %w", path, err)
    }

    if info.IsDir() {
        return f.handleDirectory(cleanPath, path)
    }

    // Read regular file
    content, err := fs.ReadFile(f.root, cleanPath)
    if err != nil {
        return nil, "", fmt.Errorf("read file %s: %w", path, err)
    }

    // Detect MIME type (returns full type with charset)
    mimeType := mime.TypeByExtension(filepath.Ext(path))
    if mimeType == "" {
        mimeType = "application/octet-stream"
    }

    return content, mimeType, nil
}

func (f *FilesystemProvider) handleDirectory(cleanPath, path string) ([]byte, string, error) {
    // Try README.md first
    readmePath := filepath.Join(cleanPath, "README.md")
    if content, err := fs.ReadFile(f.root, readmePath); err == nil {
        return content, "text/markdown", nil
    }

    // Directory listing disabled
    if !f.dirIndex {
        return nil, "", fmt.Errorf("%w: %s", ErrDirListingDisabled, path)
    }

    // Generate listing
    entries, err := fs.ReadDir(f.root, cleanPath)
    if err != nil {
        return nil, "", fmt.Errorf("read directory %s: %w", path, err)
    }

    content := GenerateMarkdownListing(path, entries)
    return content, "text/markdown", nil
}

// internal/provider/dirlisting.go
func GenerateMarkdownListing(path string, entries []fs.DirEntry) []byte {
    var listing strings.Builder

    fmt.Fprintf(&listing, "# Directory: %s\n\n", path)

    // Sort: directories first, then alphabetically
    slices.SortFunc(entries, func(a, b fs.DirEntry) int {
        if a.IsDir() != b.IsDir() {
            return cmp.Compare(b.IsDir(), a.IsDir())
        }
        return cmp.Compare(a.Name(), b.Name())
    })

    for _, entry := range entries {
        name := entry.Name()

        // Skip hidden files
        if strings.HasPrefix(name, ".") {
            continue
        }

        if entry.IsDir() {
            fmt.Fprintf(&listing, "- [%s/](%s/)\n", name, name)
        } else {
            fmt.Fprintf(&listing, "- [%s](%s)\n", name, name)
        }
    }

    return []byte(listing.String())
}
```

### Handler Implementation

```go
// internal/server/handler.go
type Handler struct {
    provider         provider.Provider
    registry         renderer.RendererRegistry
    templateRenderer template.Renderer
    siteConfig       *config.SiteConfig
}

func NewHandler(
    provider provider.Provider,
    registry renderer.RendererRegistry,
    templateRenderer template.Renderer,
    siteConfig *config.SiteConfig,
) *Handler {
    return &Handler{
        provider:         provider,
        registry:         registry,
        templateRenderer: templateRenderer,
        siteConfig:       siteConfig,
    }
}

func (h *Handler) ServeContent(w http.ResponseWriter, r *http.Request) {
    // 1. Read file + get MIME type
    content, mimeType, err := h.provider.ReadFile(r.URL.Path)
    if err != nil {
        h.handleError(w, r, err, r.URL.Path)
        return
    }

    // 2. Content negotiation
    acceptedTypes := ParseAccept(r.Header.Get("Accept"))
    normalized := NormalizeMimeType(mimeType)

    accepted := false
    for _, mt := range acceptedTypes {
        if mt.Matches(normalized) {
            accepted = true
            break
        }
    }

    if !accepted {
        w.Header().Set("Content-Type", "text/plain")
        w.WriteHeader(http.StatusNotAcceptable)
        w.Write([]byte("Not Acceptable: server can only provide " + normalized))
        return
    }

    // 3. Get renderer
    contentRenderer, err := h.registry.Get(normalized)
    if err != nil {
        h.handleError(w, r, err, r.URL.Path)
        return
    }

    // 4. Render content
    output, outputMimeType, err := contentRenderer.Render(r.Context(), content)
    if err != nil {
        h.handleError(w, r, err, r.URL.Path)
        return
    }

    // 5. Determine final MIME type
    finalMimeType := outputMimeType
    if finalMimeType == "" {
        finalMimeType = mimeType // Preserve full MIME type from provider
    }

    // 6. Serve based on output MIME type
    finalNormalized := NormalizeMimeType(finalMimeType)
    if finalNormalized == "text/html" {
        h.serveHTML(w, r, output)
    } else {
        h.serveRaw(w, output, finalMimeType)
    }
}

func (h *Handler) serveHTML(w http.ResponseWriter, r *http.Request, htmlContent []byte) {
    context := &template.TemplateContext{
        Site: h.siteConfig,
        Page: template.PageContext{
            Content:     template.HTML(htmlContent),
            Breadcrumbs: template.GenerateBreadcrumbs(h.provider, r.URL.Path),
        },
    }

    rendered, err := h.templateRenderer.Render(r.Context(), "layout.html.tmpl", context)
    if err != nil {
        h.handleError(w, r, err, r.URL.Path)
        return
    }

    w.Header().Set("Content-Type", "text/html; charset=utf-8")
    w.Header().Set("Content-Length", strconv.Itoa(len(rendered)))
    w.WriteHeader(http.StatusOK)
    w.Write(rendered)
}

func (h *Handler) serveRaw(w http.ResponseWriter, content []byte, mimeType string) {
    w.Header().Set("Content-Type", mimeType)
    w.Header().Set("Content-Length", strconv.Itoa(len(content)))
    w.Header().Set("Cache-Control", "public, max-age=300")
    w.WriteHeader(http.StatusOK)
    w.Write(content)
}

func (h *Handler) handleError(w http.ResponseWriter, r *http.Request, err error, path string) {
    statusCode := classifyError(err)

    slog.Error("Request failed",
        slog.Int("status", statusCode),
        slog.String("path", path),
        slog.String("error", err.Error()),
    )

    w.Header().Set("Content-Type", "text/html; charset=utf-8")
    w.WriteHeader(statusCode)

    switch statusCode {
    case http.StatusNotFound:
        w.Write([]byte("<h1>404 Not Found</h1>"))
    case http.StatusForbidden:
        w.Write([]byte("<h1>403 Forbidden</h1>"))
    default:
        w.Write([]byte("<h1>500 Internal Server Error</h1>"))
    }
}
```

- `Provider.ReadFile()` signature changed:
  - Before: `ReadFile(path string) ([]byte, error)`

  - Added: `ServerConfig` with `DefaultIndex` and `DirIndex`

- Template rendering interface unchanged
- Template context structure unchanged
- Middleware unchanged
- Server interface unchanged

## Decision Log

**Critical Decisions:**

- **MIME Normalization:** Use `mime.ParseMediaType()` to strip parameters before registry lookup
- **Registry.Get() Return:** `(ContentRenderer, error)` for idiomatic error handling
- **Registry Collisions:** Warn with `slog.Warn`, then override (enables testing/plugins)
- **Wildcard Matching:** Registry supports exact → type/_ → _/\* lookup order
- **PassthroughRenderer:** Register `*/*` wildcard (simplest, no maintenance)
- **Provider Context:** No context parameter (maintains stdlib `fs.FS` compatibility)
- **Provider Type:** `fs.StatFS` interface value, not `*os.FS` pointer
- **Directory Listing:** Extract to `GenerateMarkdownListing()` package function
- **MIME Registration:** In `MarkdownRenderer` `init()` (co-location with usage)
- **Parser Pooling:** ❌ DO NOT POOL (gomarkdown library constraint)

**HTTP Compliance:**

- **Accept Header:** Parse with `sort.SliceStable` (preserves client preference order for equal q-values)
- **Content Negotiation:** Return 406 Not Acceptable when client can't accept MIME type
- **Status Codes:** 403 for disabled features, 404 for not found, 499 for canceled, 504 for timeout
- **Headers:** Always include Content-Length, Cache-Control for raw content

**Error Handling:**

- **Sentinel Errors:** `ErrDirListingDisabled` (403), `ErrNotFound` (404)
- **Error Wrapping:** All errors wrapped with `fmt.Errorf("%w", err)`
- **Classification:** `classifyError()` function for status code mapping

**Security:**

- **DirIndex Default:** `false` (secure by default, no information disclosure)
- **Hidden Files:** Skip files starting with `.` in directory listings
- **Path Traversal:** `os.DirFS()` provides built-in protection

**Extensibility:**

- **Custom Renderers:** ~10 lines of code to add new renderer
- **Provider Abstraction:** Works with any `fs.FS` implementation (filesystem, S3, database)
- **Template Wrapping:** Handler decides based on output MIME type only

**Testing:**

- **Table-Driven Tests:** Recommended for all components
- **Fuzz Testing:** Recommended for MarkdownRenderer
- **Panic Recovery:** Optional in Handler (nice to have)
