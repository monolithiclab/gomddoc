# Client-Side Strings Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the `<html>` `data-*` attributes and the annotations `labels` with namespaced
`<script type="application/json" data-gmd-i18n="…">` blocks read through one shared helper, `gmd-i18n.mjs`.

**Architecture:** A template function `i18nStrings` emits a namespace's translations (keys sharing a prefix) as a
JSON data block next to each module in `scripts-shared`. Modules import `i18n(namespace)` from
`/_assets/gmd-i18n.mjs`, which reads and caches only that block and offers `t` (printf-style placeholders) and `tn`
(plural selection through `Intl.PluralRules`).

**Tech Stack:** Go `html/template`, `internal/locale`, vanilla ES modules, Vitest (happy-dom), Playwright.

**Spec:** `docs/specs/20261023.client-i18n-design.md`

## Global Constraints

- Gate: `make ci` green before every commit (lint included). Commit format `type(scope): summary`, ending with
  `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Never push.
- Agents run `make ci` (which runs the UI suite only when front-end inputs changed) and `cd web && npx vitest run`;
  the controller runs the full Playwright suite once per batch.
- Tests never touch the network.
- Public names fixed by the spec: attribute `data-gmd-i18n`, template function `i18nStrings`, file
  `cmd/gomddoc/assets/shared/static/gmd-i18n.mjs` served at `/_assets/gmd-i18n.mjs`, exports `i18n`, returned
  functions `t` and `tn`.
- Keys: `copy` → `code_copy_label`, `copied` → `code_copy_done`, `aria_copy_code` → `code_copy_aria`; new
  `search_label` ("Search documentation"), `search_query` ("Search query"), `search_results` ("Search results"),
  `color_chip_label` ("Color %s"); `aria_search` stays (header button).
- Placeholders: `%s`/`%d` in order, `%[n]s`/`%[n]d` 1-based explicit index, `%%` literal; missing argument → `""`.
- Plural variant suffixes: `_zero`, `_one`, `_two`, `_few`, `_many`; `other` is the bare key.
- The owning doc changes in the same commit as the behaviour (`AGENTS.md`).

## Review Focus

- A site locale translating `annotations_removed` but not its `_few` variant, on an `ar` page: the client must use
  the page language's general form, never English's variant (Task 2 Go test, Task 1 `tn` fallback test).
- A translation containing `</script>` or `"`: the block must stay one intact, parseable JSON element (Task 2).
- A page with `search: false` or `code_copy: false`: no block for that namespace and no module (Task 3).
- Error pages: the `error` layout drops its attributes too and its copy buttons are localized (Task 3).
- A page with frontmatter `lang: "not a tag"`: `tn` must not throw; it falls back to the runtime's default plural
  rules (Task 1).

## Execution notes

### What was built

- `cmd/gomddoc/assets/shared/static/gmd-i18n.mjs`, served at `/_assets/gmd-i18n.mjs` and written to `_assets/` by
  `build`: `i18n(namespace, doc)` → `{ t, tn }`. Own string values only (inherited or non-string entries fall back
  to the key), plain-object blocks only, `Intl.PluralRules` once per document, category `other` → the bare key.
- `i18nStrings` template function (fourteenth funcMap entry); `WithLocaleKeys` / `PipelineOptions.LocaleKeys`
  replace the annotation-only option; `Bundle.T`'s variant rule covers `_zero _one _two _few _many`.
- `scripts-shared` emits `code_copy`, `search`, `annotation` and `color_chip` blocks inside each module's guard; both
  default layouts lost their `<html>` `data-*` attributes; `code-copy.mjs` is a module.
- Search escapes every label it puts in markup; the dialog, input and results list have localized names.
- Annotations read the `annotation` block; `AnnotationsConfig` is `{sourcePath, title}`; the group count label uses
  `tn`.
- Tests: Vitest for the helper, the four modules and a key-drift scan of every `t`/`tn`/`label`/`E` literal;
  Go contract tests for both layouts with each feature off; a `fr-FR` Playwright page (copy button, search
  placeholder, annotations button in French).
- Docs: guide 13 (translations in JavaScript, plurals for translators, upgrade note), guide 05, 09, 10,
  `architecture.md`, D51, ROADMAP; gomddoc-themes `docs/theme-authoring.md`.

### Release notes

- **Client strings come from JSON blocks.** UI text for code copy buttons, search, color chips and annotations is
  emitted by `scripts-shared` as `<script type="application/json" data-gmd-i18n="…">` blocks. The `data-*`
  attributes on `<html>` are no longer read. The seven downloadable themes now show these strings in the page's
  language (they were always English).
- **Renamed locale keys:** `copy` → `code_copy_label`, `copied` → `code_copy_done`, `aria_copy_code` →
  `code_copy_aria`. Rename them in `.gomddoc/locales/*.yml`; the old names are ignored.
- **New locale keys:** `search_label` (the search dialog; `aria_search` now only labels the header button),
  `search_query`, `search_results`, `color_chip_label`, `color_chip_done`. A fully translated site shows the default
  language for these until it adds them.
- **Plural variants:** `_zero`, `_one`, `_two`, `_few` and `_many` are reserved suffixes, chosen by each language's
  plural rules in the browser. Variant strings take `%d` (`annotations_open_count_one: "Annotations (%d note)"`).
  A site key ending in one of these suffixes is now treated as a plural variant by `.T`.
- **Themes that inline modules themselves** (instead of calling `scripts-shared`) must load `code-copy.mjs`,
  `search.mjs`, `gmd-color-chip.mjs` and `gmd-annotations.mjs` with `<script type="module">` and emit their
  blocks with `i18nStrings`. A theme-root `code-copy.mjs` override now runs as a module.
- **Static hosts must serve `.mjs` as JavaScript** (`_assets/gmd-i18n.mjs`); the modules import it.
- **Theme extensions** can localize their own scripts: keys with the theme's prefix in `.gomddoc/locales/`, one
  block, `i18n("<prefix>")` (guide: Internationalization).
- Default theme: the language switcher's links are readable in dark mode. Color chips keep their text after a copy.
