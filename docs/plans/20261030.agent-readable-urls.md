## Execution notes

### What was built

- **README and licence:** the README status is at v0.4.0. The install section names the four free categories and
  says for-profit use (internal docs included) needs a commercial license. A "Free license request" issue form
  (`oss-licence.yml`, label `licence`) collects requests.
- **`.md` URLs (D54):** `PathResolver.MarkdownURLPath` is the single rule. A `.md` URL serves the enriched Markdown
  with a canonical `Link` header, and every HTML page carries a `rel="alternate"` link. `gomddoc build` writes
  `{page}.md` and no `.md` stubs. Other stripped extensions still redirect, through `PathResolver.RedirectTarget`.
- **HTML links:** local `.md` links in page bodies and search results point to clean URLs, so readers stay on HTML.
  The Markdown output keeps each author's links. `/api/search` `path` is now the page URL.
- **`llms.txt` (D55):** per language, served and built. The page list comes from the navigation. A completion pass
  puts the root page first and lists every published page the navigation drops (README-only directories) under
  `## Other pages`. Exclude and noindex rules apply. Untitled entries are titled the way their page is. The MCP line
  appears in serve only.
- **MCP Registry (D56):** `server.json` lists one stdio OCI package (`-i`, `--rm`, a read-only mount). Every image is
  labelled. The release job publishes stable tags with GitHub OIDC and a checksum-pinned `mcp-publisher`. A Go
  drift test checks the label against `server.json`.
- **Fixed on the way:**
  - The build enriched French pages with the default pipeline, so their related docs came from the wrong language.
  - Pages, README pages included, listed themselves in their related docs. Related docs now compare source files.
- **Refactors from the simplify pass:**
  - Every page and Markdown URL comes from the scope's template renderer (`ContentURL`, `MarkdownURL`,
    `LangPrefix`).
  - `seo` owns `Noindex` and `SiteURL`.
  - Build resolves the Markdown renderer once per build.

### Rulings

- The `licence` identifiers stay as they are, and the visible text says "license".
- Built `.md` files keep the build's published URLs, so prev/next links end in `/`.
- Links come from `MarkdownURLPath`, not a literal `{url}.md`.
- An `index.md` canonical follows `PageURLPath`.
- `llms.txt` uses the navigation plus a completion pass.
- The `remotes` entry for gomddoc.com was dropped: it serves a fixed corpus of gomddoc's own docs.
- HTML links are rewritten to clean URLs.
- There is no release-notes file. The release text carries the breaking lines.
- Without a domain, the MCP line uses a relative URL.
- The Makefile awk lint became a Go drift test.
