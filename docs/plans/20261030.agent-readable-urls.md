# Agent-Readable URLs Implementation Plan

**Goal:** Serve enriched Markdown at `.md` URLs, generate `llms.txt`, publish to the MCP Registry on release, and
bring the README to the current release with the licence stated at install (spec
`docs/specs/20261030.agent-readable-urls-design.md`, D54, D55).

**Size:** four tasks, executed with subagent-driven development, one commit or more per task, `make ci` green after
each. Order matters: `llms.txt` links to the `.md` URLs.
