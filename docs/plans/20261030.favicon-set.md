# Favicon Set Implementation Plan

**Goal:** Ship the full favicon set and a per-site web manifest for every theme (spec
`docs/specs/20261030.favicon-set-design.md`, D53).

**Size:** one session, executed inline.

## Tasks

- [x] **1. Icons** (spec: Files): generated from the option-A SVG with the skill's recipe; the default theme's
  `static/favicon.ico` removed.
- [x] **2. Head** (spec: Head): `head-icons` partial; `theme-color` in the default theme and the seven gomddoc-themes.
- [x] **3. Manifest** (spec: Manifest): `internal/server/manifest.go`, route, build output.

## Execution notes

### What was built

- Seven files in the shared static layer; `head-icons` links them through `assetURL`, so serve and build agree.
- `/site.webmanifest` generated per site; registered on the auth group and linked with credentials.
- `theme.icons-mixed` (warning) from `assets.IconFindings`, joined to `LanguagePipeline.Findings`.
- `favicon-check.go` against `make run`'s test site: 33 of 33 checks after `theme-color` landed.
- `/simplify` pass: one icon table (`assets.ManifestIcons`) feeds `IconFiles` and the manifest, one static-layer list
  (`staticLayerDirs`) feeds `BuildStaticFS` and the warning, the manifest background follows `theme.vars` `bg`, one
  render helper for the head tests. Skipped: an `/_assets/` prefix constant (four existing literals, its own change)
  and a PageContext field for theme backgrounds (each theme keeps its own defaults).

### Rulings

- Manifest generated per site, doctor warning for a partial set (Nicolas, 2026-10-30).
- `theme-color` lives in each theme's head, since only the theme knows its backgrounds.

### Deferred

- Release notes: "**Every theme ships a full favicon set and a web app manifest.** The icon is now a blue "g", linked
  from `/_assets/`, so static builds get it too; `/site.webmanifest` is named after `meta.title`. A site with its own
  icon must put all seven files in `.gomddoc/static/` (`gomddoc doctor` flags a partial set); a `favicon.ico` in the
  content root is no longer linked."
- gomddoc-themes: the `theme-color` change works on any gomddoc; the icon links reach the themes with this release.
- Copying `favicon.ico` to the build root for browsers that ignore `<link rel="icon">` (Safari ≤ 11) was not done.
