# Math Delimiters Implementation Plan

**Goal:** Stop dollar amounts rendering as math: recognise only `` $`…`$ `` and `$$` blocks, in the Markdown parser,
and typeset the resulting `<gmd-math>` elements instead of scanning the page (spec
`docs/specs/20261030.math-delimiters-design.md`, D52).

**Size:** one session, executed inline: a single extension, one module and docs, with every spec section mapped below.

## Tasks

- [x] **1. Parser** (spec: Syntax, Server side): `internal/renderer/ext_math.go`, registered in `markdown.go`; table
  tests in `math_test.go`, including the toggles.
- [x] **2. Client** (spec: Client side): `gmd-math.mjs`; `head-shared.html.tmpl` drops auto-render, inlines the module
  and adds the display rule; annotations skip `gmd-math`; Vitest with a KaTeX stub aliased in `vitest.config.mjs`.
- [x] **3. Docs** (spec: Documentation): guide, `architecture.md`, D52, kitchen sink; gomddoc-themes
  `docs/theme-authoring.md`; gomddoc-website `docs/features.md`.
- [x] **4. Gate:** `make ci` in gomddoc and gomddoc-themes; `make run` check of the kitchen sink.

## Execution notes

### What was built

- `MathExtension`: a `$$` block parser (priority 90, interrupts paragraphs, raw content, a one-line form, content
  allowed on the marker lines, blank lines dropped) and a code-span transformer for `` $`…`$ ``, checked span by span
  so `` $`a`$`b`$ `` can't reuse the middle sign; `` \$`x`$ `` stays code. Off with `katex`.
- `<gmd-math>` typesets once per element (a reconnect keeps the KaTeX output), with KaTeX imported from
  `cdn.jsdelivr.net/npm/katex@0.16.21/dist/katex.mjs` when the first element connects; the auto-render scripts are
  gone. `TestKaTeXVersionsMatch` (`cmd/gomddoc/assets_test.go`) keeps that import and the stylesheet on one version;
  the Vitest alias matches any version.
- `/simplify` pass: a shared closing-marker helper, one write helper, an early exit when the source has no `` $` ``,
  an escape check that counts backslashes (`` \\$`a`$ `` is math), CRLF and list-item tests. Skipped: an inline
  parser in place of the code-span transformer (goldmark's code-span parsing would have to be re-implemented),
  moving the `gmd-math[display]` rule into the module (raw TeX would show inline before KaTeX loads), unexporting
  the node types (the colour-chip ones are exported).
- The seven gomddoc-themes themes needed no template change: they call the shared `head-katex` and `scripts-shared`.
  The gomddoc-website marketing theme loads no KaTeX; only its features copy changed.

### Rulings

- No single-dollar opt-in (Nicolas, 2026-10-30): `$$` and `` $`…`$ `` are unambiguous and conventional.
- No compatibility path; a release-notes line instead.

### Deferred

- Release notes for the next tag: "**Math needs `` $`…`$ `` for inline math.** Single dollar signs are no longer math
  delimiters, so prices such as $1,200 stay text; rewrite `$x$` as `` $`x`$ ``. Display math keeps `$$`, which must
  now start and end its own lines."
- The gomddoc-website features change describes the next release: push it once that release is out.
- A ```` ```math ```` fence (GitHub's third syntax) was not added.
